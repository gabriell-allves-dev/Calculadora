# 🧮 Calculadora em Python

Uma calculadora simples desenvolvida em Python para praticar lógica de programação.

## 🚀 Funcionalidades

- **Adição (+):** soma dois números.
- **Subtração (-):** subtrai dois números.
- **Multiplicação (*):** multiplica dois números.
- **Divisão (/):** divide dois números.

## 🛠️ Tecnologias utilizadas

- Python 3

## 💻 Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no terminal.
3. Execute o arquivo:

   **Executar**

## 🎯 Objetivo

Projeto desenvolvido para praticar conceitos básicos de Python, como:

- Variáveis.
- Entrada de dados (`input`).
- Conversão de tipos (`int`).
- Estruturas condicionais (`if` e `elif`).
- Operações matemáticas.
